# Fusion for personal use — limits that matter for this repo

Checked November 2026 from secondary sources; Autodesk's own pages could not be
fetched, so confirm anything critical at
<https://www.autodesk.com/products/fusion-360/personal>.

## Licence

- Non-commercial use only; under US$1,000/year revenue from it.
- Free term must be renewed periodically (sources disagree: 1 or 3 years).

## Design (CAD)

- **10 active (editable) documents** at a time. Others stay stored read-only;
  toggle which ones are editable. Unlimited total storage of archived ones.
- Full parametric modelling, sketches, assemblies, basic rendering.
- No Configurations, very limited drawings (single sheet, print/PDF only),
  no simulation, generative design or extensions.
- Export: STEP, STL, OBJ, 3MF, F3D archive; DXF only by right-clicking a
  sketch → *Save As DXF*. No IGES / SAT / DWG export.

## Manufacture (CAM)

- 2D, 2.5D and 3-axis milling toolpaths are available (one source lists only
  2/2.5-axis — confirm in your install).
- **No rapid moves**: G0 rapids are posted as G1 at the cutting feed rate, so
  jobs with lots of repositioning run slower.
- **No automatic tool changes**: one tool per posted program. Post each tool
  as its own file and change bits manually.
- No probing cycles, no 3+2 or 4/5-axis (so no rotary-axis toolpaths).
- Local simulation and the standard Grbl post processor work.

## Consequences for how we work

- One G-code file per tool, named `<part>_<op>_<bit>.nc`.
- Archive finished projects as `.f3d` in the repo and make them read-only in
  Fusion to stay under the 10-document cap.
- Models are generated by Python scripts in `projects/<name>/fusion/`, so the
  design is reproducible from the repo even if the cloud document is archived.
